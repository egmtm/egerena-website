Requirements & Installation

System Requirements

  • Windows 10 or 11 (64-bit)
  • Python 3.10 or newer
  • ~350 MB disk space (first launch)
  • No admin rights required

Installation — Installer

  1. Extract EGMd.zip
  2. Run egm-setup.exe
  3. Follow the installer
  4. Launch from Start Menu or finish screen

Portable: Extract EGMd-portable.zip to any folder or USB drive, then run EGM Downloader.vbs

First run: 1–30 seconds (depends on connection). Next runs: 1–4 seconds.
