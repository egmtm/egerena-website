What's New in v1.5.3.2 — 11/13/2026

the total package

  • New: The installer now brings everything the app runs on: Electron, Python and its packages. You no longer need Python installed, and the first launch only downloads ffmpeg and Deno.
  • Changed: Installing over version 1.5.0 or newer keeps your history, settings, ffmpeg and Deno, and removes the old program files.
  • Changed: The uninstaller removes exactly what the installer put there. It asks whether to also remove the downloaded ffmpeg and Deno, and whether to also remove your data. Yes to both removes the install folder, unless it holds files you added.
  • Security: The installer refuses a folder that is not empty and shows no sign of EGM Downloader, and the installer and uninstaller only remove old files in a folder where EGM Downloader is installed.
  • Fixed: If antivirus blocks or removes the Python that comes with the app, a message now says so and tells you to reinstall, instead of showing an error code.
  • Fixed: Every message of the installer and uninstaller is now translated in all ten languages.
  • Changed: The installer needs 64 bit Windows on an Intel or AMD processor, and says so if it cannot run. Windows 11 on ARM also works through Windows' own x64 emulation, but it is not officially supported.
  • Changed: The installer edition starts faster, how much depends on your computer.
  • Fixed: Error messages at start up no longer open behind the splash screen.
  • Security: The installer edition's program file no longer accepts the switches and variables that made it run other scripts.
  • Security: The Python that comes with the app no longer reads your own Python packages or settings, so a stray file or setting there cannot change it or run code in it.
  • Changed: The update check on launch now only tells you that an update exists. The update dialog shows the download size, and nothing is downloaded until you press Update Now.
  • Fixed: A finished update download is kept until the update is installed, so it is not downloaded again if you cancel the installer or close the app.
  • Security: The update download stops if the file is bigger than the signed update information says.
  • Privacy: Spellcheck is off and the app no longer downloads a spellcheck dictionary. Deno and pip no longer look for their own updates, and What's New reads only the notes that come with the app.
  • Privacy: The app no longer tells image servers which app is asking: no app name or Electron in the user agent, only the Chrome version number a browser sends, no referrer, and no early lookups of the links on screen.
  • Privacy: History pictures are now fetched the way a browser would, with no cookies and no referrer, and only over HTTPS.
  • Privacy: The app's own update checks and its ffmpeg and Deno downloads now identify themselves only as EGM-Downloader.
  • Privacy: Clear History now also removes the debug and error logs, empties the Console and deletes leftover request files. Import History and the 500 entry limit also delete the pictures of entries that leave the list.
  • Privacy: yt-dlp's challenge solver now comes with the app, and Update Plugins keeps it matched to yt-dlp, so it is normally not downloaded while you use the app.
  • Fixed: Check for Updates now offers yt-dlp again when the solver package does not match it, and Update Plugins reports it if the solver could not be updated.
  • Changed: The app now ignores your own yt-dlp configuration file, so options set there, like a proxy, no longer change what the app does. It also ignores your pip settings, except when it installs the yt-dlp nightly.
  • Fixed: Installing yt-dlp nightly no longer fails with "empty file" when your pip cache has a damaged copy.
  • Privacy: Portable: The launcher's npm no longer sends an audit or checks for a newer npm.
  • New: The installer folder now includes THIRD_PARTY_NOTICES.txt, with the licenses of the libraries the app bundles.
  • Electron runtime updated to v45.3.2. It no longer trusts certificates issued by eMudhra's revoked RSA intermediates.

The release in 24 seconds. It has music and plays only when you press play.

Requirements & Installation

System Requirements

  • Windows 10 or 11 (64-bit), on an Intel or AMD processor
  • Windows 11 on ARM also works through Windows' own x64 emulation, but it is not officially supported
  • Installer edition: no Python needed, it comes with the app
  • Portable edition: Python 3.10 or newer, for the first launch only
  • ~1 GB disk space
  • No admin rights required

Installation — Installer

  1. Extract EGMd.zip
  2. Run egm-setup.exe
  3. Follow the installer
  4. Launch from Start Menu or finish screen

Portable: Extract EGMd-portable.zip to any folder or USB drive, then run EGM Downloader.exe

First run: 1–30 seconds (depends on connection). Next runs: 1–4 seconds.
