What's New in v1.2.7 — 7/2/2026

stability pass

  • Fixed the "What's New" update modal never appearing after an update
  • Fixed "Download All" getting stuck if a queued item was removed mid-run
  • Fixed queue reorder arrows sometimes moving the wrong item
  • Fixed a crash when switching a subscription's format after setting a per-video quality override

Requirements & Installation

System Requirements

  • Windows 10 or 11 (64-bit)
  • Python 3.10 or newer
  • ~350 MB disk space (first launch)
  • No admin rights required

Installation — Installer

  1. Extract EGMd.zip
  2. Run egm-setup.exe
  3. Follow the installer
  4. Launch from Start Menu or finish screen

Portable: Extract EGMd-portable.zip to any folder or USB drive, then run EGM Downloader.vbs

First run: 1–30 seconds (depends on connection). Next runs: 1–4 seconds.
