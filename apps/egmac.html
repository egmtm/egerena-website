Requirements & Installation

📋 System Requirements

  • Mac with Apple Silicon (M1, M2, M3, M4, M5)
  • macOS 11.0 (Big Sur) or later
  • Python 3.10 or newer
  • ~500 MB disk space
  • No admin rights required

🔧 Installation

  1. Download EGMdM.zip
  2. Unzip the file
  3. Run EGM Downloader.dmg
  4. Drag "EGM Downloader" to Applications folder
  5. Launch from Applications
  6. Splash screen: 1–5 seconds (prepackaged — no downloads needed)

First launch: ~500 MB of dependencies will auto-install
Subsequent launches: Near-instant startup
