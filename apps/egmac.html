What's New in 1.5.0.0.8 — 10/26/2026:
citius · أصيل: reloaded

• Security: The minimum curl_cffi version is now 0.17.0, the library that lets the app download from sites that check which browser is asking. It includes the same upstream fix as brotli for how malformed compressed data is handled (CVE-2026-111497).
• Updated: The minimum yt-dlp version is now 2026.10.26, the first one that works with curl_cffi 0.17.
• Fixed: The Subscriptions window keeps showing "Fetching videos..." until the fetch has finished, also when the language loads late or two fetches of the same channel run at once.
• Fixed: The Theme Creator panel no longer slides across the window when you switch to or from Arabic.
• Fixed: More labels that stayed in English in other languages now follow the selected language.

Requirements & Installation

📋 System Requirements

  • Mac with Apple Silicon (M1, M2, M3, M4, M5)
  • macOS 13.0 (Ventura) or later
  • ~300 MB disk space
  • No admin rights required

🔧 Installation

  1. Download EGMdM.zip
  2. Unzip the file
  3. Run EGM Downloader.dmg
  4. Drag "EGM Downloader" to Applications folder
  5. Launch from Applications
  6. Splash screen: 1–5 seconds (Electron and Python are bundled in the package)

First launch: ffmpeg, ffprobe and Deno download automatically
Subsequent launches: Near-instant startup
