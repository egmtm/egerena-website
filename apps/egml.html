> INSTALLATION
─────────────────────────────────────────────────────────────────────

$ cd ~/Downloads

$ unzip EGMdL.zip && chmod +x "EGM Downloader.AppImage" && ./"EGM Downloader.AppImage"

[!] Run from terminal: Open your terminal (Ctrl+Alt+T on most distros), navigate to where you downloaded the zip, then run the command above. The AppImage will launch immediately after making it executable.
[!] First run: ~90MB ffmpeg auto-install
[!] FUSE error? Install libfuse2:
$ sudo apt install libfuse2
