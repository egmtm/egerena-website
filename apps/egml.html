v1.3 — POLYGLOT: FULL THROTTLE
  • New in-app language selector — EGM Downloader now speaks 10 languages: English, Arabic, German, Spanish, French, Italian, Japanese, Dutch, Portuguese, and Russian
  • Language auto-detects from your system on first launch, and can be changed anytime from the footer — no restart needed
  • Language selector can be hidden from Advanced settings for a cleaner footer, and re-enabled anytime
  • Downloaded subtitles now include your selected app language alongside English (when available for that video)
  • New opt-in "Upscale to selected quality" — videos smaller than the chosen quality preset are proportionally upscaled to it after download (off by default; adds pixels, not detail)
  • Video conversion (the "MP4 · H.264" compatibility format and Upscale) now uses your GPU when available, cutting CPU load and heat dramatically — automatically falls back to software encoding if no compatible GPU is found or it's busy
  • New: HDR downloads — videos with an HDR version (HDR10, HDR10+, HLG, Dolby Vision) now show it as a separate option per resolution. HDR downloads save as MKV to preserve the HDR data untouched (requires an HDR-capable display and player to actually look right)
  • Fixed Full HD/4K downloads sometimes downloading a smaller video than "Best available" on portrait video (TikTok, Shorts, Reels)
  • Fixed cancel not working during video conversion — clicking Cancel while a video was converting was silently ignored, and the conversion ran to completion anyway
  • The "Converting…" status now shows which encoder is being used (e.g. "Converting… · h264_nvenc"), so you can confirm hardware acceleration is active
  • Deno now updates alongside yt-dlp, ffmpeg, and other plugins in Advanced settings, instead of its own separate button
  • Advanced panel now shows current → latest version for optional libraries and ffmpeg when an update is available, and correctly detects updates after switching ffmpeg channels
  • Minor spacing polish — collapsed Subscriptions sidebar thumbnails, and the Update/What's New modals no longer crowd their scrollbar against the text
  • The download queue in Subscriptions now stays pinned at the top of the sidebar — with a long channel list, it used to scroll out of view
  • Site Cookies panel in Settings redesigned into a more compact, centered layout
  • Settings panel (including Site Cookies) can now be hidden from Advanced settings for a cleaner look, same as the language selector
  • Subscriptions now detects and labels members-only videos (requires the latest yt-dlp stable or nightly)
  • Deleting a custom theme now asks for confirmation first — previously deleted instantly with no way to undo
  • Removed the "Clear cache" button from Advanced settings — temp/partial files are already cleaned up automatically after every download and on every app launch
  • Fixed an issue where users were attempting to enter the Konami code
  • Ships with 500 themes
  • Backed by 117 automated tests covering security, process safety, and cross-platform consistency — all passing
  • Fixed cancelling a video conversion (H.264 fix-up or Upscale) sometimes closing the whole app instead of just that download
  • Optional libraries (curl-cffi, brotli, pycryptodomex, websockets, certifi) can now be updated in-app from Advanced settings — previously view-only on these platforms

> INSTALLATION
─────────────────────────────────────────────────────────────────────

$ cd ~/Downloads

$ unzip EGMdL.zip && chmod +x "EGM Downloader.AppImage" && ./"EGM Downloader.AppImage"

[!] Run from terminal: Open your terminal (Ctrl+Alt+T on most distros), navigate to where you downloaded the zip, then run the command above. The AppImage will launch immediately after making it executable.
[!] First run: ~90MB ffmpeg auto-install
[!] FUSE error? Install libfuse2:
$ sudo apt install libfuse2
